Dán URL Web App triển khai từ Google Sheet để kích hoạt đồng bộ 2 chiều qua Cloud giữa tất cả các máy.
📖 Hướng dẫn cấu hình Google Apps Script (1 phút)
  1. Mở file Google Sheet Công tác KHVT.
  2. Vào Tiện ích mở rộng (Extensions) > Apps Script.
  3. Dán toàn bộ mã từ file google_apps_script.js trong mã nguồn vào.
  4. Bấm Triển khai (Deploy) > Triển khai mới (New deployment):
    • Loại: Ứng dụng web (Web app)
    • Thực thi dưới dạng: Tôi (Me)
    • Ai có quyền truy cập: Bất kỳ ai (Anyone)
  5. Copy URL Web App kết thúc bằng /exec và dán vào ô trên, rồi bấm Lưu & Đồng bộ ngay.
